# 🎙️ Voice Assistant

Локальный голосовой ассистент на Python, способный распознавать речь в реальном времени, выполнять команды по открытию сайтов и отвечать на вопросы с помощью локальной языковой модели (LLM).

## ✨ Возможности

- 🎤 **Распознавание речи**: Использует библиотеку `Vosk` с легкой русской языковой моделью для быстрой транскрибации.
- 🗣️ **Активация по кодовым словам**: Ассистент начинает слушать команду только после произнесения заданных слов (например, "пелагея" или "жорик"), что экономит ресурсы и предотвращает ложные срабатывания.
- 🌐 **Управление браузером**: Может открывать заданные сайты (YouTube, Google, Roblox) по голосовой команде.
- 🤖 **Интеграция с ИИ**: Отправляет распознанный текст в локальную LLM (через LM Studio) для получения осмысленных ответов на вопросы.
- 🔊 **Озвучивание ответов**: Синтез речи для голосового ответа пользователю (через модуль `assistant_speech`).

## 🛠️ Требования

- Python **3.13** (или совместимая версия)
- Менеджер пакетов [`uv`](https://docs.astral.sh/uv/) (рекомендуется) или стандартный `pip`
- Запущенный локальный сервер **LM Studio** с загруженной моделью (в коде используется `qwen/qwen3-vl-4b`, но вы можете изменить её на любую совместимую)
- Работающий микрофон

## 📦 Установка

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/DaVinci113/voice_assistant.git
   cd voice_assistant
   ```

2. **Установите зависимости**:
   Если у вас установлен `uv` (рекомендуется, так как в проекте есть `uv.lock`):
   ```bash
   uv sync
   ```
   Или через стандартный `pip`:
   ```bash
   pip install vosk sounddevice lmstudio
   ```

3. **Скачайте модель Vosk**:
   Ассистент использует модель `vosk-model-small-ru-0.22`. Скачайте её и распакуйте в корневую папку проекта (или укажите правильный путь в `conf.py`).
   - [Скачать vosk-model-small-ru-0.22.zip](https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip)

4. **Настройте LM Studio**:
   - Запустите приложение LM Studio.
   - Загрузите и запустите локальный сервер (Local Server) с совместимой моделью.
   - Убедитесь, что сервер доступен и работает (по умолчанию на порту `1234`).

## ⚙️ Настройка

Все основные параметры вынесены в файл `conf.py` для удобного редактирования:

- `SAMPLE_RATE` и `CHUNK_SIZE`: параметры записи звука (рекомендуется не менять без необходимости).
- `MODEL_PATH`: путь к папке с распакованной моделью Vosk.
- `WAKE_WORDS`: кортеж слов для активации ассистента (например, `("пелагея", "жорик")`).
- `COMMAND_URL`: словарь команд для открытия сайтов. Вы можете легко добавить свои команды, например:
  ```python
  ('открой музыку', 'включи музыку'): 'https://music.yandex.ru/'
  ```

## 🚀 Использование

1. Убедитесь, что LM Studio запущен и модель готова к работе.
2. Запустите ассистента из терминала:
   ```bash
   python main.py
   ```
3. Дождитесь голосового приветствия.
4. Произнесите кодовое слово (например, *"Жорик"*).
5. После подтверждения готовности произнесите команду:
   - *"Открой ютуб"* (откроет браузер)
   - *"Кто ты?"* (вопрос будет отправлен в ИИ, а ответ озвучен)

## 📁 Структура проекта

```text
voice_assistant/

│   └── speech.py

├── ai_requests.py          # Тестовый скрипт для прямых запросов к API
├── conf.py                 # Файл конфигурации (модель, слова активации, команды)
├── testing.py              # Скрипты для тестирования распознавания Vosk
├── uv.lock                 # Файл блокировки зависимостей для uv
└── .python-version         # Указанная версия Python (3.13)
```
