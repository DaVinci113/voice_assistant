# 🎙️ Voice Assistant

Локальный голосовой ассистент на Python, который распознает речь в реальном времени, выполняет голосовые команды (например, открытие сайтов) и отвечает на вопросы с помощью локальной языковой модели (LLM).

## ✨ Возможности

- 🎤 **Распознавание речи**: Использует библиотеку `Vosk` с легкой русскоязычной моделью для быстрой и точной транскрибации.
- 🗣️ **Активация по кодовым словам**: Ассистент начинает слушать команду только после произнесения заданных слов (по умолчанию: "пелагея" или "жорик"), что предотвращает ложные срабатывания.
- 🌐 **Управление браузером**: Автоматически открывает заданные сайты (YouTube, Google, Roblox) по голосовой команде.
- 🤖 **Интеграция с ИИ**: Отправляет распознанный текст в локальную LLM (через LM Studio) для получения осмысленных ответов на вопросы.
- 🔊 **Озвучивание ответов**: Синтез речи для голосового ответа пользователю (через собственный модуль `assistant_speech`).

## 🛠️ Требования

- Python **3.13** (или совместимая версия, см. `.python-version`)
- Менеджер пакетов [`uv`](https://docs.astral.sh/uv/) (рекомендуется) или стандартный `pip`
- Запущенный локальный сервер **LM Studio** с загруженной языковой моделью
- Работающий микрофон и динамики

## 📦 Установка

1. **Клонируйте репозиторий**:

bash
git clone https://github.com/DaVinci113/voice_assistant.git
cd voice_assistan


2. **Установите зависимости**:
   Рекомендуется использовать `uv` (в проекте присутствует `uv.lock`):

bash
uv sync

   *Альтернатива через стандартный `pip`:*

bash
pip install vosk sounddevice lmstudio requests


3. **Скачайте модель Vosk**:
   Ассистент использует модель `vosk-model-small-ru-0.22`. Скачайте её и распакуйте в корневую папку проекта (путь указан в `conf.py`).
   - [Скачать vosk-model-small-ru-0.22.zip](https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip)

4. **Настройте LM Studio**:
   - Откройте приложение LM Studio.
   - Загрузите и запустите локальный сервер (Local Server) с совместимой моделью (в коде по умолчанию используется `qwen/qwen3-vl-4b`, но вы можете изменить это в `ai.py`).
   - Убедитесь, что сервер работает и доступен (обычно на порту `1234`).

## ⚙️ Настройка

Все основные параметры вынесены в файл `conf.py` для удобного редактирования:

- `SAMPLE_RATE` и `CHUNK_SIZE`: параметры записи звука (рекомендуется оставить по умолчанию: `16000` и `8000`).
- `MODEL_PATH`: путь к папке с распакованной моделью Vosk (например, `"vosk-model-small-ru-0.22"`).
- `WAKE_WORDS`: кортеж слов для активации ассистента. Пример: `("пелагея", "жорик")`.
- `COMMAND_URL`: словарь команд для открытия сайтов. Вы можете легко добавить свои команды:
  ```python
  COMMAND_URL = {
      ('открой ютуб', 'открой ютюб'): 'https://www.youtube.com/',
      ('открой гугл', 'открой гугол'): 'https://www.google.com/',
      ('открой роблокс', 'открой роблакс'): 'https://www.roblox.com/',
      ('открой музыку',): 'https://music.yandex.ru/',  # Ваш пример
  }

🚀 Использование
Убедитесь, что LM Studio запущен и модель готова к работе.
Запустите ассистента из терминала:

   python main.py

Дождитесь голосового приветствия.
Произнесите кодовое слово (например, "Жорик" или "Пелагея").
После звукового подтверждения готовности произнесите команду:
"Открой ютуб" (откроет браузер с YouTube)
"Кто ты?" (вопрос будет отправлен в ИИ, а ответ озвучен)
📁 Структура проекта

voice_assistant/
├── assistant_speech/       # Модуль для синтеза и воспроизведения речи
│   └── speech.py
├── main.py                 # Основной файл: логика записи, распознавания и управления
├── ai.py                   # Логика взаимодействия с локальной LLM (LM Studio)
├── ai_requests.py          # Скрипт для тестирования прямых запросов к API
├── conf.py                 # Файл конфигурации (модель, слова активации, команды)
├── testing.py              # Скрипты для тестирования распознавания Vosk
├── uv.lock                 # Файл блокировки зависимостей для uv
└── .python-version         # Указанная версия Python (3.13)
